# Job Scam Detection using AI/ML

An AI/ML-based system developed to identify potentially fraudulent job postings using machine learning and data analysis.

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Google Colab

## Features

- Job Data Preprocessing
- Exploratory Data Analysis
- Data Visualization
- Feature Analysis
- Machine Learning Model
- Job Scam Prediction
- Streamlit-based User Interface

## Project Overview

This project uses machine learning techniques to analyze job postings and identify potentially fraudulent or scam job advertisements. The system processes job-related data, analyzes relevant features, and predicts whether a job posting may be legitimate or potentially fraudulent.

## Project Status

Ongoing – Additional features and Streamlit deployment are currently in progress.
